Après avoir cloné le projet depuis GitHub, commencez par installer les dépendances PHP avec la commande composer install, puis installez les dépendances Node.js en exécutant npm install. Ensuite, configurez l’environnement en copiant le fichier .env.example en .env et générez une clé d’application avec php artisan key:generate. Assurez-vous de configurer la base de données dans le fichier .env,
puis appliquez les migrations en exécutant php artisan migrate. Enfin, lancez le serveur Laravel avec php artisan serve et démarrez le serveur Vue.js avec npm run dev pour accéder à l’application.
